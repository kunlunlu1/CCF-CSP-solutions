## 只针对 CSP 前三题的精简必刷清单（按优先级）

### P0（必须先刷，最高优先级）
- 模拟与细节处理（字符串、日期时间、矩阵、规则判定）
- 排序 + 自定义比较器（结构体排序、多关键字排序）
- 前缀和/差分（1D、2D）
- 双指针（区间统计、去重、滑动窗口基础）
- 基础贪心（按规则排序后线性处理）
- 哈希计数（频次统计、去重、映射）

### P1（第二阶段，稳定前3题）
- 二分答案（“最小最大值”类）
- BFS（网格最短步数、连通块）
- 简单 DFS（遍历/回溯，小规模）
- 单调队列（滑窗最值）
- 栈与队列基础（括号匹配、表达式/过程模拟）

### P2（有余力再补，冲稳和容错）
- 并查集（连通性动态合并）
- KMP/Trie（字符串查询类，出现频率低于前两档）
- 简单 DP（线性 DP、基础背包）
- 图最短路基础（Dijkstra 模板，少量题会用）

### 刷题顺序建议（只看执行顺序）
- 先刷：模拟 → 排序 → 前缀和差分 → 哈希
- 再刷：双指针 → 贪心 → 二分答案 → BFS
- 最后补：DFS/单调队列/并查集/简单 DP

### 训练目标（面向前三题）
- 目标1：前两题“无脑拿满”
- 目标2：第三题至少拿到基础分 + 常规优化分
- 目标3：代码模板化（输入、排序、二分、BFS、前缀和）减少失误
