## 只针对 CSP 前三题的精简必刷清单（按优先级）

> 对应你截图里的「算法基础课」位置使用：先在对应讲里刷下面这些小类，再回到真题实战。

### P0（必须先刷，最高优先级）
- 模拟与细节处理（字符串、日期时间、矩阵、规则判定）
- 排序 + 自定义比较器（结构体排序、多关键字排序）
- 前缀和/差分（1D、2D）
- 双指针（区间统计、去重、滑动窗口基础）
- 基础贪心（按规则排序后线性处理）
- 哈希计数（频次统计、去重、映射）

### P1（第二阶段，稳定前3题）
- 二分答案（“最小最大值”类）
- BFS（网格最短步数、连通块）
- 简单 DFS（遍历/回溯，小规模）
- 单调队列（滑窗最值）
- 栈与队列基础（括号匹配、表达式/过程模拟）

### P2（有余力再补，冲稳和容错）
- 并查集（连通性动态合并）
- KMP/Trie（字符串查询类，出现频率低于前两档）
- 简单 DP（线性 DP、基础背包）
- 图最短路基础（Dijkstra 模板，少量题会用）

### 放到「算法基础课」里的对应位置（按章节）
- 第一讲 基础算法：排序、二分答案、前缀和/差分、双指针、位运算基础。
- 第二讲 数据结构：栈与队列、单调队列、哈希计数、并查集（可放这里或图论前后补）。
- 第三讲 搜索与图论：BFS、简单 DFS、图最短路基础（Dijkstra）。
- 第四讲 数学知识：先做常用取整/取模/边界处理，服务模拟题精度与规则实现。
- 第五讲 动态规划：简单 DP（线性 DP、基础背包）作为补强。
- 第六讲 贪心：基础贪心（按规则排序后线性处理）。
- 字符串相关：KMP/Trie 作为低频补充，不影响前三题主线时可后置。

### 刷题顺序建议（只看执行顺序）
- 先刷：模拟 → 排序 → 前缀和差分 → 哈希
- 再刷：双指针 → 贪心 → 二分答案 → BFS
- 最后补：DFS/单调队列/并查集/简单 DP

### 训练目标（面向前三题）
- 目标1：前两题“无脑拿满”
- 目标2：第三题至少拿到基础分 + 常规优化分
- 目标3：代码模板化（输入、排序、二分、BFS、前缀和）减少失误

## 模拟与细节处理训练方案（可直接执行）

### 1) 题前（先降失误）
- 固定一套读题清单：输入范围、边界、规则优先级、输出格式。
- 先写 3~5 个手造样例：最小值、最大值、空/全相同、边界切换点。

### 2) 题中（强制流程化）
- 先写“状态定义”和“步骤顺序”，再写代码。
- 每完成一个步骤就做一次小验证（打印中间结果或对照样例）。
- 把高风险细节单独处理：日期进位、字符串下标、矩阵越界、四舍五入/取整规则。

### 3) 题后（形成可复用模板）
- 复盘只记三件事：错因、触发条件、避免动作。
- 建一个“模拟错题本”分类：边界错、读题错、实现顺序错、格式错。
- 同类题 48 小时内二刷，要求一次 AC。

### 4) 每周训练安排（实操）
- 每天 1~2 题纯模拟题，限时 45~60 分钟。
- 每周做一次“无调试提交”训练：写完只看一遍就交，逼自己提升一次正确率。
- 每周整理 1 份个人模板（输入、字符串处理、日期函数、矩阵遍历）。

### 5) 量化目标
- 一周内把“非思路性错误”降到 30% 以下。
- 两周内前两题模拟类题目一次通过率达到 70%+。
